Features 新特性

11 ITEMS
01

支持新 API Darkmode.validate()，用于校验 Dark Mode 转换效果，并支持豁免规则 data-ignore-dm="low-contrast text-bg-gradient"。

02

支持新 API Darkmode.reset()，用于重置 Dark Mode 转换算法。

03

支持新 API Darkmode.getDmBgColor()，用于根据 Light Mode 背景色转换生成 Dark Mode 背景色。

04

支持新 API Darkmode.getDmFontColor()，用于根据 Light Mode 前景色转换生成 Dark Mode 前景色。

05

支持新 API Darkmode.colorToCssString()，用于把颜色对象转成 css 色值 rgb() | rgba()。

06

API Darkmode.run() 新增入参 container，往 container 中插入新节点时可重建样式继承关系。

07

支持新属性 Darkmode.htmlClass，获取强制暗黑模式时给 html 添加的 class。

08

支持新配置属性 defaultLightWebviewColor 和 defaultDarkWebviewColor，并对所有颜色配置属性支持透明度写法。

09

支持 lch()、oklch()、lab()、oklab()、color() 颜色模型。

10

新增 DOM 操作钩子 getStyle、setStyle、getClass、setClass、getAttr 和 setAttr，可自定义 DOM 操作逻辑。

11

支持编辑器 Dark Mode，所写即所见并所得。→ 配合 FEATURES 02–07 & 10 使用

02

Optimizations 算法优化升级

05 ITEMS
01

全链路改造透明度计算规则，解决“敏感肌”问题。
查看 CASE #1 对比 ↘

02

修正渐变 / 半透明底色的转换规则：渐变底色改用「实际写进样式」的色值参与计算，避免把浅色渐变误判成深底（黑底黑字），也避免把未被转换的渐变误判成深底（浅底浅字）。
查看 CASE #2 对比 ↘

03

统一渐变的 color stop 转换结果，使渐变真正转成纯色。
查看 CASE #2 对比 ↘

04

优化图片补色逻辑，区分黑白灰与彩色，前者使用 Light Mode 原色进行补色，后者使用 Dark Mode 转换色进行补色且背景图上方的节点不再跳过 Dark Mode 转换。

05

颜色处理库从 color 迁移到 colorjs.io。

Bug Fixes 修复

04 ITEMS
